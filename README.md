# 🛒 Online Order Calculator
### ระบบคำนวณราคาสินค้าออนไลน์ด้วย TypeScript

โปรเจกต์นี้เป็นส่วนหนึ่งของการเรียนรู้การเขียนโปรแกรมด้วยภาษา JavaScript และ TypeScript โดยพัฒนาระบบคำนวณราคาสินค้าออนไลน์ ซึ่งสามารถคำนวณราคาสินค้ารวม ส่วนลดจากคูปอง และภาษีมูลค่าเพิ่ม (VAT 7%) พร้อมระบบตรวจสอบความถูกต้องของข้อมูล (Data Validation)

## 📖 2. ความรู้ที่ได้เรียนรู้ (What I Learned)

### 2.1 JavaScript

JavaScript เป็นภาษาโปรแกรมที่ใช้ในการพัฒนาเว็บไซต์และระบบต่าง ๆ โดยได้เรียนรู้คำสั่งพื้นฐาน ได้แก่

| คำสั่ง | ความหมาย |
|---|---|
| `const` | ประกาศตัวแปรที่ไม่สามารถกำหนดค่าใหม่ได้ |
| `let` | ประกาศตัวแปรที่สามารถเปลี่ยนค่าได้ |
| `function` | สร้างฟังก์ชัน |
| `if` | ตรวจสอบเงื่อนไข |
| `return` | ส่งค่ากลับจากฟังก์ชัน |
| `try` | ทดลองทำงานของคำสั่ง |
| `catch` | จัดการข้อผิดพลาด |
| `throw` | สร้างข้อผิดพลาด |
| `console.log()` | แสดงผลข้อมูลใน Console |

### 2.2 TypeScript

TypeScript เป็นภาษาที่พัฒนาต่อยอดจาก JavaScript โดยเพิ่มระบบตรวจสอบชนิดข้อมูล (Static Typing) ช่วยลดข้อผิดพลาดในการเขียนโปรแกรม

หัวข้อสำคัญที่ได้เรียนรู้ ได้แก่

**Type Annotations**

ใช้กำหนดชนิดข้อมูลให้กับตัวแปร

```typescript
let price: number = 1000;
let productName: string = "Coffee";
```

**Union Types**

ใช้กำหนดค่าที่สามารถเลือกใช้ได้จากหลายตัวเลือก

```typescript
type PaymentType =
  | "CASH"
  | "PROMPTPAY"
  | "CREDIT_CARD";
```

**Interface**

ใช้กำหนดโครงสร้างของข้อมูล

```typescript
interface OrderInput {
  orderId: string;
  price: number;
  quantity: number;
  discountPercent?: number;
  paymentType: PaymentType;
}
```

**Parameter Type และ Return Type**

ใช้กำหนดชนิดข้อมูลที่รับเข้าและส่งกลับจากฟังก์ชัน

```typescript
function calculateOrder(
  order: OrderInput
): OrderResult {
  // Calculation
}
```

**Optional Chaining (`?.`)**

ใช้เข้าถึงข้อมูลอย่างปลอดภัยเมื่อค่าที่อยู่ก่อนหน้าอาจเป็น null หรือ undefined

```typescript
order.orderId?.trim();
```

**Nullish Coalescing (`??`)**

ใช้กำหนดค่าเริ่มต้นเมื่อข้อมูลเป็น null หรือ undefined

```typescript
const discountPercent =
  order.discountPercent ?? 0;
```

## 🧮 3. หลักการคำนวณราคาสินค้า (Calculation Logic)

ระบบคำนวณราคาสินค้าโดยใช้สูตรดังนี้

| รายการ | สูตรคำนวณ |
|---|---|
| ราคาสินค้ารวม | ราคา × จำนวนสินค้า |
| ส่วนลด | ราคาสินค้ารวม × (ส่วนลด ÷ 100) |
| ราคาหลังหักส่วนลด | ราคาสินค้ารวม − ส่วนลด |
| VAT 7% | ราคาหลังหักส่วนลด × 0.07 |
| ยอดชำระสุทธิ | ราคาหลังหักส่วนลด + VAT |

### ตัวอย่างการคำนวณ

กำหนดให้
- ราคาสินค้า: 1,000 บาท
- จำนวนสินค้า: 2 ชิ้น
- ส่วนลด: 10%
- ภาษีมูลค่าเพิ่ม: 7%

ผลการคำนวณ

| รายการ | จำนวนเงิน |
|---|---:|
| ราคาสินค้ารวม | 2,000 บาท |
| ส่วนลด 10% | 200 บาท |
| ราคาหลังหักส่วนลด | 1,800 บาท |
| VAT 7% | 126 บาท |
| **ยอดชำระสุทธิ** | **1,926 บาท** |

## 🛡️ 4. ระบบตรวจสอบข้อมูล (Data Validation)

โปรแกรมมีระบบตรวจสอบข้อมูลก่อนคำนวณ เพื่อป้องกันข้อผิดพลาดที่อาจเกิดขึ้น

| เงื่อนไข | การทำงาน |
|---|---|
| ราคาสินค้าติดลบ | แจ้ง Error |
| ราคาสินค้าเป็น 0 | แจ้ง Error |
| จำนวนสินค้าเป็น 0 | แจ้ง Error |
| จำนวนสินค้าติดลบ | แจ้ง Error |
| จำนวนสินค้าเป็นทศนิยม | แจ้ง Error |
| ส่วนลดติดลบ | แจ้ง Error |
| ส่วนลดเกิน 100% | แจ้ง Error |
| ไม่ระบุส่วนลด | กำหนดเป็น 0% |
| ไม่ระบุรหัสคำสั่งซื้อ | แจ้ง Error |

## 🧪 5. การทดสอบโปรแกรมด้วย Vitest

Vitest เป็นเครื่องมือสำหรับทดสอบการทำงานของโปรแกรม JavaScript และ TypeScript

การทดสอบโปรแกรมแบ่งออกเป็น 2 กรณีหลัก

**กรณีที่ 1: การทดสอบข้อมูลปกติ**
- คำนวณราคาสินค้าได้ถูกต้อง
- คำนวณส่วนลดได้ถูกต้อง
- คำนวณ VAT 7% ได้ถูกต้อง
- รองรับส่วนลด 100%
- กำหนดส่วนลดเริ่มต้นเป็น 0%

**กรณีที่ 2: การทดสอบข้อมูลผิดพลาด**
- ราคาสินค้าติดลบ
- จำนวนสินค้าเป็น 0
- จำนวนสินค้าเป็นทศนิยม
- ส่วนลดเกิน 100%
- รหัสคำสั่งซื้อเป็นค่าว่าง

### คำสั่งติดตั้งและทดสอบ

ติดตั้ง Vitest และ TypeScript

```bash
npm install -D vitest typescript
```

รันชุดทดสอบ

```bash
npm test
```

ตัวอย่างผลลัพธ์ที่คาดหวัง

```text
Test Files  1 passed (1)
Tests       8 passed (8)

PASS
```

หมายเหตุ: ต้องรันคำสั่งทดสอบจริงก่อนจึงจะยืนยันผล PASS ได้
